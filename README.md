# Swat Garden Center Management System 🌱

A full-stack, database-driven Business Management System (mini-ERP) built with PHP, MySQL, HTML, CSS, and JavaScript. Designed specifically to manage retail operations, inventory, and accounting for a garden center.

## 🚀 Features
* **Secure Authentication:** Admin login system to protect business records.
* **Master Inventory Tracking:** Manage plant categories, pricing, and environmental needs.
* **Automated Low-Stock Alerts:** Dashboard warnings when plant stock drops below safe levels.
* **Dual-Entry Accounting Ledger:** Unified daily sales and expenses tracking with net profit calculations.
* **Interactive Analytics:** Real-time data visualization using Chart.js to track monthly performance.
* **Dynamic QR Code Generation:** Automated API integration to generate printable QR labels for physical plant pots.
* **Professional Reporting:** Print-ready, monthly financial summary reports (Exportable to PDF).

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Chart.js)
* **Backend:** PHP
* **Database:** MySQL
* **Architecture:** Custom CRUD operations with relational database modeling.

## ⚙️ Installation & Setup
1. Clone this repository to your local machine.
2. Move the folder to your local server environment (e.g., `htdocs` for XAMPP).
3. Open phpMyAdmin and create a new database named `swat_garden_center`.
4. Import the included `swat_garden_center.sql` file into the new database.
5. Launch the project in your browser at `http://localhost/swat-garden-center-management-system/login.php`.
6. **Default Login Credentials:**
   * Username: `admin`
   * Password: `swat123`
